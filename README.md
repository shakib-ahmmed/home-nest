# Home Nest

Home Nest is a full-stack real estate application that allows users to post, view, update, and review properties. Built with **React**, **Node.js**, **Express**, and **MongoDB**, the platform provides an intuitive interface for property management and review tracking.

---

## Features

### User Features
- **Authentication**: Users can log in with their email (or via OAuth if implemented).
- **Add Property**: Post new properties with details such as name, description, category, price, location, and images.
- **Update Property**: Edit existing property details (private route).
- **Delete Property**: Remove properties that the user has posted.
- **View Properties**: Browse all available properties.
- **Property Details**: See detailed information including images, description, and reviews.
- **Reviews & Ratings**: Users can leave reviews and ratings for properties.
- **My Reviews**: Track all submitted reviews in one place.

### Admin/Private Routes
- **Update Property**: Edit property information via a form pre-filled with existing data.
- **View User Reviews**: See all reviews submitted by a logged-in user.

---

## Tech Stack

### Frontend
- **React.js** with hooks and context API
- **React Router v6** for routing
- **Tailwind CSS** for styling
- **React Toastify** for notifications
- **Lucide-react** icons

### Backend
- **Node.js** & **Express.js**
- **MongoDB Atlas** for database
- **CORS** enabled for API requests
