# 🏠 Home Nest

**Home Nest** is a modern **full-stack real estate platform** that allows users to browse, post, update, and review properties. Built with **React**, **Node.js**, **Express**, and **MongoDB**, it provides a clean and intuitive interface for property management, review tracking, and property discovery.


---

## 🔗 Live Demo

[Explore Home Nest](https://home-nest-84a80.web.app/add-property)

---

## ⚡ Features

### User Features
- **Authentication**: Sign up and log in with email/password.
- **Add Property**: Post new properties with details (name, description, category, price, location, images).
- **Update Property**: Edit your property details.
- **Delete Property**: Remove your properties from the platform.
- **View Properties**: Browse all available listings.
- **Property Details**: View detailed info including description, images, and reviews.
- **Reviews & Ratings**: Leave feedback and rate properties.
- **My Reviews**: Track all submitted reviews in one place.

### Admin / Private Routes
- **Update Property**: Edit property info via a pre-filled form.
- **View User Reviews**: See all reviews submitted by a logged-in user.

## 🛠 Tech Stack

### Frontend
- **React.js** (hooks & context API)  
- **React Router v6** for client-side routing  
- **Tailwind CSS** for responsive styling  
- **React Toastify** for notifications  
- **Lucide-react** icons  

### Backend
- **Node.js** & **Express.js**  
- **MongoDB Atlas** as the database  
- **CORS** enabled for API requests  

### Other Tools
- **Firebase** (for authentication if used)  
- **Netlify / Vercel** (for frontend hosting)
